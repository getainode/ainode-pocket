Overview
One endpoint for the fleet
OpenAI-compatible
http://127.0.0.1:8430/v1

/v1/models is the union across every registered device. /v1/chat/completions routes by model id to a device that has it loaded, one request at a time per device, so concurrent callers queue instead of failing with device error 150004.

Add a device

          

            
            
            
            
          

          

            Leave the address blank and press Find devices: Pocket broadcasts on
            udp/39217 and checks any USB link this machine is plugged into. A box
            answers on Wi-Fi and USB at once and reports both, so it registers
            once with both addresses and prefers the USB link, which does not move.
          

          

            The key is read from ~/.tiinyapps/device.json or the
            TiinyOS app's local storage when you leave it blank, and each
            candidate is tried against the device before it is kept.
          

          

            
            
          

          

            A scan probes 254 addresses for an unauthenticated discovery
            responder on port 39218. It touches nothing else.
